One entry for the make.fun bounty "Funniest Sign on a Haunted Server Room Door":
a single sign, 120 characters or fewer, for the door of a haunted server room.
`main.py` writes that line to `entry.txt`.

Run:

    python3 main.py

Writes `entry.txt` into `$OUTPUT_DIR` (default `/output`), creates the directory
if needed, and prints `LEN=<n>`. Exits non-zero when the text is empty or longer
than 120 characters.
